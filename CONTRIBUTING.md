# Contributing to LingStack

Thank you for helping improve LingStack.

1. Open an issue before large changes.
2. Keep the public build free of personal paths, credentials, private registries, and bundled Agent/Skill definitions.
3. Run `npm ci`, `npm run ci`, `cargo fmt --check --manifest-path src-tauri/Cargo.toml`, and `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`.
4. Add or update tests for behavior changes.
5. Do not submit third-party Agent or Skill definitions unless their license and redistribution rights are explicit.

By contributing, you agree that your contribution is licensed under Apache-2.0.
