# 灵栈 0.12.0 审核说明

本版本改进本地资产的版本比较、辅助选择、审计报告浏览与导出一致性。以下说明用于本次商店版审核，不沿用旧版本的提交编号或构建编号。

## 商店版本边界

- 商店版模型接入仅支持本机运行的 Ollama，地址限 localhost 或回环地址。远程模型主机和模型凭证由后端拒绝；无需模型账户即可使用本地资产浏览、比较和选择功能。
- 文件访问保留系统沙盒限制。用户通过系统文件夹选择器授权访问目录；不会因为本次更新自动扩大目录权限。
- 比较和建议在本机处理，不执行定义文件内的指令，不调用模型进行质量排名。候选按钮只预填治理表单，保存选择仍需用户明确操作。
- 不捆绑个人资产、凭证或机器专属配置。独立分发渠道的应用不是本次商店审核二进制。

## 本次改进与建议审核步骤

1. 启动应用，授权一个含测试定义文件的目录。查看同一资产的两个不同内容版本，进入“版本对比与选择”。未成功读取双方正文时，不提供选版建议。
2. 读取两个版本，查看原文件和受支持的核心指令比较。核心相同不代表权限、配置或整个文件等价；计算达到上限时显示不完整提示。
3. 在“帮我选择”中指定目标来源，或选择保留当前版本、优先已有验证。建议说明登记来源或验证记录依据，不将来源匹配当作已验证兼容。缺少足够依据时不推荐某一侧。
4. 点击候选按钮，确认仅预填候选哈希；不保存表单时关闭再打开，不应产生新的已选版本。有效验证必须对应当前资产、当前选定内容哈希，且记录有效、内容版本仍存在、未待刷新。
5. 运行只读审计，使用分页查看返回的报告。分页覆盖后端返回的记录，不表示已取消后端报告数量上限。
6. 在授权的测试目录进行导出。导出前核对定义内容哈希，使用校验后的内容；内容不一致时拒绝将其作为旧版本导出。失败不覆盖已有导出文件。
7. 进入模型接入，确认仅提供本机 Ollama，并拒绝非回环地址与模型凭证。模型服务未启动时，本地资产比较不应依赖模型连接。

## 已验证范围与提交前检查

截至本说明编写时，开发版本已通过前端静态检查、单元测试、Web 与 macOS 原生构建及相关 Rust 检查。macOS 开发版已实测双版本读取、证据不足不推荐、指定来源后的建议、候选预填且不自动保存，以及审计分页与末页按钮状态。导出哈希一致性与失败路径已有回归测试。

0.12.0 独立分发签名包已复核双版本读取、证据不足不推荐、来源建议、候选预填，以及关闭后未保存选择不持久化。商店版 0.12.0（120）已构建为 Apple silicon / Intel 通用安装包，复核发行签名、沙盒授权、隐私扫描，并确认 PKG 解包后的内容与签名应用一致。

商店发行签名应用在本机直接启动失败；从无附加 Finder 元数据的副本启动也返回相同系统启动错误，因此最终商店包的目录授权、本机模型限制和核心交互运行验收仍待完成。上传后必须先通过 Apple 构建处理与可运行分发途径完成验收，再送审；不能用独立分发包的实测代替商店包。真实模型调用、Intel 真机和屏幕阅读器未纳入本轮运行验收。本文档本身不表示上传、审核或发布已完成。
