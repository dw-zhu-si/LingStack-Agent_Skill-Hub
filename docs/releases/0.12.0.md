# 灵栈 0.12.0 更新说明

本版围绕“发现资产 → 比较版本 → 辅助选择 → 验证 → 导出”完善本地工作流。

## 新增能力

- 版本对比支持核心指令与完整原文、行级差异和长结果分页。
- “帮我选择”按准备使用的来源和保留当前/优先验证偏好给出可解释建议；证据不足时明确提示，不产生无依据的质量排名。
- 建议可一键填入治理候选，用户最终确认后才保存选择。
- 本地定义原文阅读与有界全文搜索，显示读取失败、跳过和截断状态。

## 修复与优化

- 修复部分混合语言、长名称和特殊标点名称的资产 ID 碰撞。
- 统一当前有效验证状态，避免待刷新或失效哈希继续显示为已验证。
- 导出前验证定义内容哈希，失败不覆盖现有导出文件。
- 修复模型编辑异步响应覆盖、项目匹配不精确和部分审计结果不可访问。
- 补全 11 种界面语言的辅助选版文案，更新存在已知告警的依赖。

## 升级说明

名称识别修复在主动刷新资产后生效。受影响资产可能需要重新确认治理选择；不会自动把旧记录映射到不同的新资产，也不会改写第三方 Agent/Skill 定义。

辅助建议来自本机登记和已有验证记录，不代表真实模型效果排名。实际效果应使用同一任务验证。

## 发行渠道

GitHub 独立发行版与 Mac App Store 沙盒版分别打包。两者均提供本地版本比较与辅助选择；商店版保留用户授权目录和本机模型服务限制。具体下载、签名、公证及商店审核状态以渠道页面和制品清单为准。
